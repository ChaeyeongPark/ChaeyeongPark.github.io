교육 콘텐츠 제작 Agent

web app · 교육 콘텐츠 제작 자동화

교육과정을 개설할 때마다 같은 정보를 반복 입력하고 상세페이지·썸네일·eDM·홍보 문구를 각각 제작해야 하는 비효율 발생

반복되는 제작 업무의 공통 입력값과 출력 규격을 정리하고, 생성형 AI를 활용해 내부 업무용 웹앱을 기획·개발했습니다. 과정 정보 한 번으로 LMS 상세페이지 HTML, 썸네일, 카카오톡 홍보 카드, eDM HTML, 채널별 홍보 문구를 생성하도록 구성했습니다.

과정 정보 입력 → 테마 선택 → 초안 생성 → 화면에서 수정 → 다운로드·복사로 이어지는 작업 흐름을 설계했습니다. 테마 7종과 이미지 출력 규격을 정의해 여러 교육과정에 재사용할 수 있도록 했으며, 팀원들에게 공유해 실무 활용을 지원했습니다.
